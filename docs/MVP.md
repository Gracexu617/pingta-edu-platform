# 教育内容中台 MVP

## 当前目标

先实现一条最小可用链路：

资料录入 -> 资料整理 -> 检索参考 -> 生成草稿 -> 人工审核

## Web Admin Shell v1

当前网页已升级为生产后台壳子，包含：

- 总览监控
- 来源管理
- 采集任务
- 内容库
- 知识检索入口
- 大 V 分析入口
- 常州教育情报入口
- 高校知识库入口
- 报告中心
- 系统配置

说明：

- 来源管理已接后端数据库；资料、任务、草稿仍使用浏览器本地数据兜底。
- 自动采集、RAG、高校库、大 V 蒸馏为模块入口，后续逐个接真实后端。
- 旧 MVP 功能已迁入后台模块。

## 第一版能力

- 手动录入公众号、视频号、高校官网、教育资讯和自有资料。
- 管理指定来源，包括公众号、视频号、高校官网和教育资讯网站。
- 从来源创建采集任务，并跟踪待采集、处理中、已完成状态。
- 采集任务可关联到链接导入；资料入库后自动完成任务。
- 给资料添加标题、来源、标签和正文。
- 支持一键导出和导入工作区 JSON 备份。
- 页面显示当前 AI 配置状态。
- 类型、种子数据、备份构建和备份校验已抽到统一数据层。
- 来源读写已通过 `app/lib/platform-api.ts` 接入 FastAPI；其它模块继续走本地适配器。
- 在资料库中搜索标题、摘要、正文和标签。
- 基于资料生成公众号文章、视频号脚本、专业文章草稿。
- 在审核中心标记草稿为需修改或可发布。
- 自动保存资料和草稿到浏览器本地。
- 预留 `/api/generate` 生成接口；未配置模型时使用本地模板。
- 预留 `/api/organize` 资料整理接口；未配置模型时使用本地规则。
- 预留 `/api/import-url` 链接导入接口，可读取普通网页标题和正文。

## 链接导入边界

- 支持普通可访问网页。
- 不绕过登录、验证码、反爬或平台限制。
- 如果页面正文提取失败，继续使用手动粘贴正文入库。

## 启用 AI 生成

复制 `.env.example` 为 `.env.local`，填写：

```bash
AI_PROVIDER=doubao
DOUBAO_API_KEY=你的火山方舟 API Key
DOUBAO_MODEL=你的豆包模型或推理接入点 ID
DOUBAO_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
```

本项目不依赖 OpenAI。除豆包外，也可把 `AI_PROVIDER` 设为 `deepseek` / `qwen` / `zhipu` / `kimi`（逗号分隔可多厂商兜底），并填写对应 `*_API_KEY`。没有配置时，平台会继续使用本地模板和本地整理规则。

## 暂不做

- 不直接自动发布公众号或视频号。
- 不做强爬虫。
- 不绕过平台规则采集内容。
- 不把提示词和工作流写死在模型调用里。

## 工程结构

- `app/page.tsx`：当前 MVP 工作台页面。
- `app/lib/platform-api.ts`：前端 API 契约、后端来源客户端和本地适配器。
- `app/lib/workspace.ts`：工作区类型、种子数据、备份构建和备份解析。
- `app/api/import-url/route.ts`：普通网页链接导入。
- `app/api/organize/route.ts`：资料整理接口。
- `app/api/generate/route.ts`：草稿生成接口。
- `app/api/settings/route.ts`：基础配置状态接口。
